## What is the immediate next step — exact fixes for the 6 failing tests

The 6 failures have 3 diagnosed root causes (all small; no re-architecture). Apply in this order:

### Fix 1 — TUIProvider abstract-method instantiation (4 failures)
Adding the 6 `create_rag_v2_*` abstract methods to `IUIProvider` (the correct location for the provider contract) made `TUIProvider` (at `src/agentx/ui/tui/provider.py:137`) uninstantiable — it doesn't implement them. v2 is console-only, so TUIProvider MUST refuse them.

- `test_create_rag_v2_view_factory_present`

**File to edit**: `src/agentx/ui/tui/provider.py` (read first; find the class definition at line 137; add the 6 stubs alongside the existing `create_*` methods).

### Fix 2 — `ConsoleProvider` NameError in `load_commands` (1 failure)
`main_controller.py:85` references `ConsoleProvider` in `isinstance(self._provider, ConsoleProvider)`, but `ConsoleProvider` is imported only under `TYPE_CHECKING` (added this session) — at runtime it's `NameError: name 'ConsoleProvider' is not defined`.

**Fix options** (pick one):
- (A) Add a runtime import inside `load_commands` (lazy, circular-safe): `from agentx.ui.providers import ConsoleProvider` at the top of `load_commands`.
- (B) Duck-typed check (no import): `if self._provider is not None and hasattr(self._provider, "create_rag_v2_view"):` instead of `isinstance`. This is the cleaner choice — it checks the capability, not the type, and is circular-import-free.

**Recommended: (B)** — replace the `isinstance(self._provider, ConsoleProvider)` with `hasattr(self._provider, "create_rag_v2_view")`. The 1 failure this fixes:
- `test_load_commands_registers_rag_command` (the `MainController(provider=MagicMock(spec=IUIProvider))` instantiation dies at `load_commands` due to the NameError; `MagicMock(spec=IUIProvider)` does NOT have `create_rag_v2_view` as a concrete attr since it's an ABC method — verify the mock exposes it; if not, option (A) is safer).

**Note**: after Fix 1 (TUIProvider stubs), `MagicMock(spec=IUIProvider)` will have the 6 `create_rag_v2_*` methods as mock attrs (because they're now on the ABC), so option (B) `hasattr` check would route TUI mocks to v2 too — which is WRONG for the TUI path. **Therefore option (A) (runtime `isinstance` import) is actually the correct choice** — it distinguishes the real ConsoleProvider class from a TUIProvider/mock. Go with (A).

### Fix 3 — `create_summarization_tool_middleware` real-deepagents call in fallback test (1 failure)
The installed deepagents IS importable, so `_DEEPAGENTS_AVAILABLE=True` at module load. The fallback test (`test_service_falls_back_to_create_agent_without_deepagents`) does `_flush_deepagents()` (clears the cache) then `_fresh_service_module()`, but `import deepagents` in the re-imported module SUCCEEDS (deepagents is installed), so the ctor takes the deepagents path and calls the real `create_summarization_tool_middleware(self._llm, self._backend)` with `MagicMock()` as the llm → `TypeError: 'expects model to be a BaseChatModel instance'`.

**Fix**: in the fallback test, force `import deepagents` to fail by poisoning `sys.modules` BEFORE `_fresh_service_module()`:
```python
_flush_deepagents()
sys.modules["deepagents"] = None  # type: ignore[assignment]
# Also poison the submodules the try-except imports.
sys.modules["deepagents.backends"] = None
sys.modules["deepagents.middleware.summarization"] = None
try:
    mod = _fresh_service_module()
    with patch.object(mod.AIService, "get_current_llm", return_value=MagicMock()):
        svc = mod.RagV2AgentService(repository_path="/tmp/rag_v2_test")
    assert svc._agent is not None
    assert getattr(svc, "_backend", None) is None  # fallback path: no StateBackend
finally:
    # Clean up the poisoned entries.
    for key in ("deepagents", "deepagents.backends", "deepagents.middleware.summarization"):
        sys.modules.pop(key, None)
    _flush_deepagents()
```
Setting `sys.modules[<name>] = None` makes `import <name>` raise `ImportError` (CPython contract). The 1 failure this fixes:
- `test_service_falls_back_to_create_agent_without_deepagents`

**Also**: the test currently asserts `getattr(svc, "_subagents", None) is not None or svc._agent is not None` — tighten to assert `svc._backend is None` (the fallback path sets `_backend = None`, per the source at `rag_v2_agent_service.py` line ~`self._backend = None`).
