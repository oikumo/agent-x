## 3. Analysis-layer behaviors to port (38 tests, from `test_analysis.py` collect)

- **`_explore` core** (shared BFS, §31): BFS from M0; `predecessors` map `{marking: (prev, transition|null)}` with initial `(None, None)`; `edges` map `{marking: [(transition, successor), …]}` in `enabledTransitionsAt` order; `complete`; `explored_states` = distinct visited markings incl. initial.
- **`reachable_markings(max_states)`** → `{markings: frozenset, predecessors, complete, explored_states}` — happy (2 states, preds pinned) + truncated (`max_states=1` → 1 state, `complete=False`).
- **`reachability_graph(max_states)`** → `{states: frozenset, edges, complete}` — happy full edges + **truncated records edges to unvisited successors** (`(1,0)→[("t1",(0,1))]` with `complete=False`).
- **`firing_sequence_to(result, target)`** → shortest BFS-edge-count sequence (predecessor back-walk + reverse), `[]` for initial, `None` when absent; `None` is a proof ONLY if `result.complete` (truncated case: reachable-but-not-found → `None`).
- **`deadlocks(max_states)`** → sorted tuple of markings with no enabled transitions; truncated → reason verbatim: `"State-space exploration was truncated; listed deadlocks are only those among explored states."`
- **`bounds(max_states)`** → `{bounded, bounds: per-place max, complete, reason}`; complete ⇒ `bounded=True`; truncated ⇒ `bounded=None` + `"State-space exploration was truncated; boundedness is unknown."` (never overclaim).
- **`incidence_matrix()`** → `C[p][t] = W(t,p) − W(p,t)` rows=`place_order`, cols=`transition_order`; degenerate shapes: places-only → `[[], []]`, transitions-only → `[]`, empty → `[]`.
- **`place_invariants()` / `transition_invariants()`** → basis of `Cᵀx=0` / `Cy=0` via exact Fraction nullspace, **coprime int tuples** (`_coprime_int_vector`: LCM-scale → gcd-content divide → negate if first nonzero negative); degenerate: places-only → identity basis `[(1,0),(0,1)]`, transitions-only → identity for T-invariants, empty → `[]`.
- **`transition_liveness(t, graph)`** → reverse multi-source BFS over graph; incomplete graph → `AnalysisResult(None, False, len(states), "Reachability graph is incomplete; liveness is unknown.")`; no enabling state → `(False, True, n)`; else `(can_reach == all, True, n)`.
- **`is_live(graph)`** → all transitions live; incomplete → `None` + global-liveness reason; empty net → `(True, True, 1)` (F1 uniform rule).
- **`strongly_connected_components(graph)`** → Tarjan over graph vertex set; neighbors in edge-tuple order; start nodes sorted; **edge targets outside `graph.states` skipped** (truncated graphs — no phantom components); empty net → `[frozenset({()})]`.
- **Determinism (§29):** repeated calls equal; deadlocks sorted.

**Result dataclasses (frozen, exact — F3 no extra fields):** `AnalysisResult(value: bool|None, complete, explored_states, reason?)`, `ReachabilityResult(markings, predecessors, complete, explored_states)`, `ReachabilityGraph(states, edges, complete)`, `DeadlockResult(deadlocks, complete, explored_states, reason?)`, `BoundResult(bounded: bool|None, bounds, complete, reason?)`.

## 5. Findings (traps the design must pin)

- **B1 — Marking identity in TS.** Python markings are hashable tuples usable as dict/set keys. TS arrays are reference-typed. Port pins `markingKey(m): string` (`m.join(",")` — unambiguous: markings are non-negative ints) for visited/predecessors/edges maps; arrays of markings re-materialized from keys in deterministic order.
- **B2 — Exact rational arithmetic (TA gotcha #1).** `nullspace` is Fraction Gauss–Jordan to FULL RREF (free columns → basis vectors `1 @ free`, `−rows[pivot][f]` @ pivots); `_coprime_int_vector` LCM-scales, divides by gcd-content, negates when first nonzero is negative. **Any float anywhere diverges.** Port pins a hand-rolled `fraction.ts` (normalized num/den, den > 0; `gcd` mirroring `math.gcd`: `gcd(0,0)=0`, `gcd(0,x)=|x|`; lcm = `a*b // gcd(a,b)`), zero new deps. A lib would need its gcd/negation semantics verified against `math.gcd` — hand-rolled 80-LOC mirror is exactness-safe and keeps the tool dependency-free (project independence ethos).
- **B3 — Truncation order (TA gotcha #2).** `_explore` when `len(visited) >= max_states` mid-edge-list: record the edge to the unvisited successor, do NOT enqueue it, set `complete=False`, finish the CURRENT state's remaining edges, then break the outer loop. The truncated graph test pins exactly this (`(1,0)` retains its `t1` edge to unvisited `(0,1)`). Port copies the loop structure 1:1.
- **B4 — `explored_states` semantics.** = distinct visited markings incl. initial (`len(visited)`), NOT edge count. `transition_liveness`/`is_live` report `len(graph.states)` as `explored_states` (F1: empty net `is_live` → `(True, True, 1)`).
- **B5 — Result-type parity.** Frozen dataclasses → readonly interfaces with the exact fields (no extras, F3); equality = deep field compare (frozensets → sorted arrays). `value` is `boolean | null` (null = unknown, never overclaimed).
- **B6 — Deterministic iteration order.** `enabledTransitionsAt` returns code-point-sorted transitions (model port) → edges in that order; SCC start nodes sorted; reverse-liveness stack/iteration sorted; deadlocks sorted. TS `sort` with the existing `compareCodePoints` for strings; numeric lexicographic for marking arrays.
- **B7 — SCC on truncated graphs.** Edges to targets outside `graph.states` (only possible from truncation) are skipped — no phantom single-state components. Recursive Tarjan depth fine for v1 nets (Python recursion parity; the library accepts the same risk).
- **B8 — Vector generator placement.** Dev-time Python script under `tools/petri-net-studio/scripts/` (runs via `uv run`; not bundled; independence lint unaffected — it scans `src/` .ts(x) only). Vectors under `shared/petri-net/conformance/analysis-v1/` (D5/D8-locked; `shared/META.md` already reserves the dir). Rejected: pytest-integrated fixture (couples vector generation to agentx test runs — vectors must be static data the independent TS suite reads).
- **B9 — Deterministic vector serialization.** frozenset markings → arrays sorted lexicographically; predecessors/edges keyed by canonical marking strings; reason strings verbatim; net reuses the FORMAT §8 canonical doc (schema-valid, so the TS `documentFromJson` builds the net directly).
- **B10 — `max_states` dial = user control, never hidden.** `max_states: number | null` (null = unlimited, Python `None`). Dashboard dial: bounded number input (1..N) + "unlimited" toggle; every verdict renders `value`/`complete`/`reason` (D10); truncated results visually distinct (❓ unknown badge + verbatim reason; bounded-truncation renders `bounded=None` as unknown, never "bounded").
- **B11 — TDD driver mismatch (A11 precedent).** `omt_tdd` is pytest-shaped; this feature's runner is Vitest. Declared in the Programming phase scope; manual red→green discipline with pasted evidence in the test report.
- **B12 — Analysis is derived, not stored.** Analysis is engine-pure over M0 (never the live marking): memoized from `toNet(doc)` in the dashboard layer (React `useMemo` keyed on doc identity + `max_states`); no document/format change; a structural edit invalidates it naturally (net identity changes). `max_states` is dashboard-local UI state (not persisted to the document — the format is M0-only).
